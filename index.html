Questions

The things agents ask.

Does it need to be accurate to the millimetre?

It's built to the floorplan's dimensions, so room sizes and layout are right. Like any floorplan it's illustrative, not a survey — we say so on every walkthrough.

The property's empty / dated. Is that a problem?

It's the best case. We furnish every room, so buyers see the potential rather than the wallpaper. If you'd rather it matched the current finishes, send the photos and we'll follow them.

How do I put it on Rightmove?

Add the link in the "virtual tour" field of the listing, exactly as you would a 360° tour. It also embeds on your own website and sends fine over WhatsApp.

What do you need from me?

The listing link, or the floorplan image. Photos help with finishes but aren't required. Multi-floor homes: one plan per floor.

Who's behind this?

Wander is run by a civil engineering student at the University of Dundee who builds every walkthrough personally. Small on purpose — you'll always deal with the same person.
